# Студия маникюра «Красота на Крыльях» — Сайт

Коммерческий проект: лендинг для студии маникюра. Задача заключалась в создании современного, быстрого и адаптивного сайта с акцентом на визуальную привлекательность и плавные анимации.

> **Демо:** 

##  Технологический стек
- **Фреймворк:** Nuxt 3 (Vue 3, Composition API)
- **UI-библиотека:** Nuxt UI + Tailwind CSS
- **Анимации:** Кастомные компоненты на `IntersectionObserver` (Reveal), инерционная прокрутка на `requestAnimationFrame`
- **Формы:** Валидация, отправка заявок с защитой от спама (Honeypot)

##  Ключевые реализованные фичи
- **Кастомный компонент «Кинолента» (`FilmCarousel`):** Бесконечная карусель с автопрокруткой, поддержкой drag-and-drop (мышь/тач), физикой инерции и бесшовным зацикливанием.
- **Анимации при скролле (`Reveal`):** Оптимизированный компонент появления элементов с использованием `IntersectionObserver` и `requestAnimationFrame` (без сторонних тяжелых библиотек).
- **Адаптивная верстка:** Полная поддержка мобильных устройств, планшетов и десктопов.
- **Работа с формами:** Отправка данных через API-роуты Nuxt, обработка состояний загрузки, успеха и ошибок. Встроенная защита от ботов (Honeypot-поле).
